Connection format

Use your own HTTPS gateway with CORS enabled for this site's origin. Keep provider API keys on your gateway. This tester does not store API keys.

POST { model, prompt, images: [dataURL, …], n: 1 | 4 }

Response:
{ images: ["data:image/png;base64,…", …] }

Return separate PNG, JPEG, or WebP data URLs. Four-image mode expects four outputs. Requests time out after 5 minutes. Use the prompt to specify views; this version sends one request per model.
